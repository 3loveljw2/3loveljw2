## 🧠 我在做什么

- **用 AI 搭"越用越懂自己的系统"**：记忆分层、经验蒸馏、技能自我进化——把 AI 从"问答工具"变成"会成长的工作伙伴"
- **造 AI 技术团队**：10 个身份技能包（架构/实现/审查/文档/发布/演示/安全/社区/策划/记忆管家），会进化、带实证、可双路径使用
- **AI 自主命题**：让 AI 按专家规范出卷，人只做决策，AI 做生成与计算
- **方法论开源**：把踩坑经验蒸馏成可复用的方法论（含公开的踩坑日志），让更多人少走弯路
